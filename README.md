# Skybound Spider

Skybound Spider is a Roblox script that enhances the gameplay experience by providing players with the ability to fly to any stage in the game. It includes a server script for teleporting players to specified stages via chat commands and a client script for creating a user-friendly interface to select stages. This script is perfect for players who want to quickly navigate between stages, saving time and effort.

## Install

1. Download the script files from the GitHub repository.
2. Open your Roblox Studio project.
3. Navigate to the `ServerScriptService` in the Explorer.
4. Create a new script and name it `FlyToStageScript.server.lua`.
5. Copy the contents of the `FlyToStageScript.server.lua` file from the repository and paste it into the new script.
6. Navigate to the `StarterPlayerScripts` in the Explorer.
7. Create a new script and name it `StageSelectionScript.client.lua`.
8. Copy the contents of the `StageSelectionScript.client.lua` file from the repository and paste it into the new script.
9. Save and publish your Roblox game.

## Use

1. Start the Roblox game.
2. Use the chat command `/fly <stageName>` to teleport to the specified stage.
3. Alternatively, use the in-game GUI to select the desired stage and click on it to teleport.
